# Algorithmic-Developement-from_scratch

This repo documents my process of learning algorithmic developmnent by implementing optimisation methods, numerical method algorithims, graphs based algorithims and metaheuristics from scratch in Python.

### Note:
The notebooks are used as working notebooks, hence do not represent polished or production ready code/implementations. They include exploratory code, intermediate attempts, visual experimentation, long comments, debugging statements and notes as I work through and understand different algorithims. 

My main aim is to build and develop my understanding of algorithims and their implmentations from a first principles basis. Testing different behaviours of algorithims and functions involved and recording my notes along the way.
